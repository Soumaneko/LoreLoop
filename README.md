# LoreLoop · 续章

> 一个本地运行的 LLM 互动叙事（文字冒险）引擎：以历史原文为依据、由幕后导演推进局势、先检定后叙事、每回合均可编辑与回溯。

[Releases 下载](https://github.com/Soumaneko/LoreLoop/releases) · [问题反馈](https://github.com/Soumaneko/LoreLoop/issues) · [MIT License](LICENSE)

![LoreLoop 阅读界面](docs/assets/reading-main.png)

LoreLoop 让你用自然语言扮演角色、推进故事。你只需要选择一个预设世界，或设定大致的背景与主角，系统会自动负责行动检定、幕后事件调度、长期记忆召回与世界状态维护。

## 设计初衷

直接用网页端大模型或酒馆类工具进行长线文字冒险时，通常会遇到两个比较棘手的问题：

1. **手动维护上下文和状态过于繁琐**：长线故事需要定期手动做剧情总结、更新人物与世界档案。而压缩提炼后的摘要往往会丢失细节，导致后续生成频繁出现遗忘和幻觉，玩家不得不花大量精力去修正设定。
2. **纯对话模式缺乏方向感，容易滑向网文套路**：大模型的长处是能把各种突发展开的逻辑圆回来，但单纯“一问一答”的回合制交互很难自己产生主线推力。如果不借助现成的知名作品设定（如同人世界），或者不提前配置一套复杂的剧情状态机，故事很容易退化为训练语料中最常见的网文套路。

LoreLoop 的出发点就是解决这两个问题：**提供一个不需要手动维护记忆、同时有人物动机和幕后事件推着故事往前走的系统。**

## 核心机制与体验

### 以历史原文为依据，自动维护世界状态
历史正文始终是唯一的上下文依据。系统会自动记录当前时间、地点、在场角色、资产物品，以及人物档案、世界设定与未决事项；这些结构化档案仅作为检索索引，用于在长线流程中定位并召回关联回合的**原始正文**，减少摘要压缩带来的信息丢失。

### 幕后 Director 推进局势
NPC 拥有独立的背景与动机，幕后 Director 模块会根据当前处境编排事件、引入冲突或提供线索，为开放式的回合交互提供持续的剧情方向。

<img src="docs/assets/codex-and-records.png" alt="人物档案与世界记录" width="560" />

### 先检定、后叙事
玩家的自然语言输入会先被解析为具体行动并完成骰点检定，再由叙事模块根据既定的成败结果撰写正文——成功会切实兑现，失败也是真实的失败。
- 支持三档检定难度。
- 骰点信息可按沉浸感偏好切换展示方式。

### 草稿确认、意见重写与可控回溯
生成的回合在确认前均为可编辑草稿，确认后才正式归档并更新世界状态：
- 支持直接编辑正文、重新判定 或输入修改意见让系统局部修订/重新构思。
- 支持回合级 撤销 / 重做，以及独立的本地多存档管理与 ZIP 导出 / 导入。
- 提供三套界面主题与多种中文字体排版。

## 快速开始

### Windows（推荐）

1. 前往 [Releases](https://github.com/Soumaneko/LoreLoop/releases) 下载最新的 `LoreLoop-*-win-x64.zip`。
2. 完整解压后运行其中的 `LoreLoop.exe`（若提示缺少 WebView2 Runtime，运行包内的 `Install-WebView2.cmd` 即可）。
3. 在界面顶部进入 **模型服务**，选择服务商或填写自定义接口与 API Key，测试连接后启用。
4. 回到 **旅程库**，直接体验内置预设开局，或新建自定义世界。

> **关于 Windows 安全提示**：由于当前为未签名的独立开源程序，首次运行 `LoreLoop.exe` 时可能触发 Windows SmartScreen 提示，点击“更多信息 → 仍要运行”即可。

### 内置开局预设

如果不想一开始从零填写世界观，可以直接选用内置的 3 套完整预设开局（也随时支持完全自定义创建）：

- **传统西幻 ·《灰桥镇的集市日》**：护卫商队归来的旅人，在河谷边境小镇面对新的委托与旅程。
- **武侠 ·《临江渡》**：独行刀客行至江南渡口，在茶棚与渡船纠纷中卷入江湖人情与利益纠葛。
- **仙侠 ·《青岚山的春水》**：宗门药圃杂役面临旱情与外门考核的两难，在灵石与前程间做出取舍。

<img src="docs/assets/journey-library.png" alt="新建旅程与开局预设" width="760" />

### macOS / Linux（本地网页运行）

目前暂未提供 macOS / Linux 桌面安装包，可通过 Python 3.11 在本地启动网页端：

```bash
pip install -r requirements.txt
python -m app.debug_server
```

启动后在浏览器访问 `http://127.0.0.1:8765/` 即可游玩。

## 模型配置与选项

- **支持接口**：需要自备大模型 API Key。内置常见服务商目录，支持多种协议以及兼容的自定义接口。
- **本地隐私**：API Key 与服务配置仅保存在本机，不会随存档 ZIP 导出。
- **常用开关**：
  - **后校验**：开启后会在正文生成后额外核对历史事实一致性。
  - **一键确认**：希望连续推进、不逐回合审阅草稿时可开启自动确认。

## 适合谁 & 当前边界

LoreLoop 目前的设计思路带有比较明确的偏好，仍在持续打磨中，未必适合所有需求：

- **比较适合**：喜欢单人长线互动小说 / 自由跑团、看重前后逻辑一致性、希望系统自动维护记忆并推进剧情的玩家。
- **目前不包含**：酒馆（SillyTavern）角色卡导入、立绘 / 语音生成、多人联机跑团。
