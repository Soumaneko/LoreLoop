# LoreLoop · 续章

[Releases 下载](https://github.com/Soumaneko/LoreLoop/releases) · [问题反馈](https://github.com/Soumaneko/LoreLoop/issues)

LoreLoop 是一个基于大语言模型的本地互动叙事（文字冒险）引擎。你只需要设定大致的世界背景与主角，用自然语言输入行动，系统会负责行动检定、幕后事件调度、长期记忆检索与世界状态维护。

## 设计初衷

直接用网页端大模型或酒馆类工具进行长线文字冒险时，通常会遇到两个比较棘手的问题：

1. **手动维护上下文和状态过于繁琐**：长线故事需要定期手动做剧情总结、更新人物与世界档案。而压缩提炼后的摘要往往会丢失细节，导致后续生成频繁出现遗忘和幻觉，玩家不得不花大量精力去修正设定。
2. **纯对话模式缺乏方向感，容易滑向网文套路**：大模型的长处是能把各种突发展开的逻辑圆回来，但单纯“一问一答”的回合制交互很难自己产生主线推力。如果不借助现成的知名作品设定（如同人世界），或者不提前配置一套复杂的剧情状态机，故事很容易退化为训练语料中最常见的网文套路。

LoreLoop 的出发点就是解决这两个问题：**提供一个不需要手动维护记忆、同时有人物动机和幕后事件推着故事往前走的系统。**

目前的设计思路带有明显的特定偏好，仍在持续打磨中，未必适合所有的需求。

## 核心机制

LoreLoop 的每一回合按以下方式运作：

- **以历史原文为依据**：历史正文始终是唯一的上下文依据。系统自动维护的总结、人物档案与世界档案仅作为间接检索索引，用于在长线流程中定位并召回关联回合的原文，解决摘要压缩带来的信息丢失问题。
- **Director 推进局势**：NPC 拥有独立的背景与动机，幕后 Director 模块会根据当前处境编排事件、引入冲突或提供线索，为开放式的回合对话提供持续的剧情方向。
- **先检定、后叙事**：玩家的自然语言输入会先解析为具体行动并完成骰点检定，再由生成模块根据检定结果撰写正文。
- **草稿确认**：生成的回合在确认前均为可编辑草稿，支持直接修改正文、Reroll 或附带要求重写，确认后才正式归档并更新状态。

## 快速开始

从 [Releases](https://github.com/Soumaneko/LoreLoop/releases) 下载最新的 Windows x64 压缩包，完整解压后运行 `LoreLoop.exe`（若提示缺少 WebView2 Runtime，运行包内的 `Install-WebView2.cmd` 即可）。

需要自备大模型 API Key，在界面中选择服务商或配置自定义接口。

## 开发

Linux 开发环境建议使用 Python 3.11，安装 `requirements.txt` 后运行 `python -m app.debug_server`，浏览器访问 `http://127.0.0.1:8765/`。
