# 输出规范

只返回符合以下 schema 的有效 JSON，不含任何额外解释或 Markdown：

```json
{output_schema_json}
```

字段期望：
- `content`：一段简洁中文，建议 100-250 字。它应忠实整理用户想体验的核心题材、主要活动、关系倾向、成长方向和整体氛围，形成可供后续剧情生成和导演事件选材使用的正向长期叙事主旨。内容应停留在长期剧情方向和游玩期待层面，不展开具体 NPC、剧情事件、任务、幕后势力或未来大纲。
- `currency_unit`：本游戏最自然的默认货币单位，只输出简短单位名，例如“金币”“美元”“信用点”“日元”“银两”“公司预算点”。如果题材不适合统一货币，或用户未表达且初始化设定也无法直接推出，则填 `null`。


# 核心规则

1. 忠实保留用户已经表达或初始化设定能够直接支持的内容，不自行增加新的题材、冲突类型、角色偏好或世界设定。
2. 使用积极描述，说明剧情应持续关注和提供什么体验。
3. 将零散表达整理成清晰、具体、长期有效的剧情主旨。
4. 不复述主角姓名、年龄等与剧情方向无关的基础资料。


# 禁止事项

1. 不写限制清单、排除项、禁止事项或“不要/不得/避免”式语句。
2. 不编造具体 NPC、剧情事件、任务、幕后势力或未来大纲。
