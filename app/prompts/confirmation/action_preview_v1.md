# 输出规范

只返回符合以下 schema 的有效 JSON，不含任何 Markdown 标记、前缀、后缀或解释：

```json
{output_schema_json}
```

输出只包含 previews。previews 必须正好包含 4 个 ActionPreview，四条 label 必须互不重复。

每个 ActionPreview 按以下字段填写：

- level：2-4字的游玩风格/策略标签。不要拘泥于刻板分类，应根据当下场景的核心冲突动态定名（如正面威慑、环境利用、试探虚实、潜行迂回、利益交换、孤注一掷、借力打力、情感动员等）。4 个选项必须体现出不同的策略侧重与态度方向。
- label：简短有力的第二人称行动短句，必须包含明确动作与行动对象/手段（如“利用倒塌的案几作为掩体并向守卫投掷飞刀”、“按住剑柄冷笑，言语试探对方底细”）。严禁使用“谨慎行动”、“进行观察”等抽象意图，不得照抄 Next Action Directions 原句。
- good_result：一句话描述行动顺利时可能打开的正面剧情走向，只写收益类型与局势转机（如“可能迫使对方让步并吐露内情”、“有机会撕开包围圈切入后方”）。不得剧透隐藏真相或确定确定结果。
- risk：一句话描述行动可能面临的隐患、代价或暴露风险（如“可能激怒对方引发直接冲突”、“可能暴露潜伏位置”）。不得写成确定惩罚。如果没有风险就如实写出来。


# 核心规则

1. 场景自然延展：预览必须紧扣 Scene Facts 和 CurrentState 中的具体场景、在场 NPC、物品与环境约束，严禁凭空虚构未出现的地点、物品或角色。
2. 多维策略差异：4 个选项必须具备真实的决策张力，建议从不同视角发掘可选路径：
    - 环境与物理交互：推倒重物遮挡、借助高低差/暗角潜伏、灭火引暗、破坏机关、利用现场特殊物体（如酒瓶、绳索、帘幕）。
    - 社交与心理博弈：
        - 强硬/施压：亮出身份/后招威胁、揭穿对方谎言、严阵以待按剑戒备。
        - 柔性/交涉：抛出筹码谈判、假意顺从/示弱诱敌、诉诸旧情/同理心说服。
        - 语言试探：话中带话套底细、故意说错引导对方纠正。
    - 战术与局势操纵：挑起第三方与敌方的矛盾、声东击西制造混乱、借力打力、拖延时间等待救援/变化。
    - 信息与细节搜寻：观察对方腰间钥匙/微表情/伤势、搜寻角落账册、潜伏视线死角监听。
    - 果断抉择与非常规行动：丢弃重物/次要目标迅速撤离、挺身而出替人承受、使用未知/危险物品铤而走险。
    - 日常休整与生活质感：点名茶名酒享用、客栈/营地小憩恢复精力、修理保养武器与装备、犒劳同伴体魄。
    - 才艺、专业与技能展现：展现医理辨药/解毒技能、展示琴棋书画/才艺惊艳旁人、展示机关破解/古文解读专业能力、露一手绝活确立声望。
    - 伪装、潜伏与身份扮演：假冒特定身份（如商贾、官差、仆役）、模仿对方言语口音/举止、伪造印信信件、装疯卖傻/佯装醉酒降低对方戒心。
    - 探索、勘测与空间解密：登高俯瞰城郭/地形全貌、辨识特殊植被/水文特征、寻觅隐蔽小道/密道后门、尝试触发古怪雕文与机关。
    - 商贸交易与资源筹谋：讨价还价买卖物资、以物易物抵扣、评估商品真伪品质、打听黑市/稀有资源渠道。
    - 民俗、仪式与风土融入：遵循当地禁忌/拜谒风俗、参与民间赌局/集会/庆典、向老者请教风土传说、履行门规/宗教仪式。
    - 内心沉淀与立场抉择：静坐整理已知线索与逻辑、暗自评估局势利弊、履行侠义/誓言做出善举、冷眼旁观保持中立立场。
  3. 真实性与边界：Scene Facts 是权威依据。可合理利用 CurrentState 中的物品与NPC，但不得编造隐藏功能或未公开后果。所有公开描述不得泄露导演后台信息、NPC私密心理或隐藏真相。


# 禁止事项

1. 禁止输出 schema 以外的任何字段。
2. 禁止生成重复或同质化的行动路径（例如 4 个选项全是某个行动的不同打法）。
3. 禁止确定未来：good_result 和 risk 只能表达可能的倾向，不得宣告“必然成功”或“必然失败”。
4. 禁止格式污染：只输出符合 schema 的 JSON，不含 Markdown、解释文字或额外字段。
