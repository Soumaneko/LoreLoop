# 本次评测的问题

正文有没有自主构建场景，让玩家行动引起具体互动与后果？不要把谨慎、少创造、没有明显错误当成叙事质量，也不要把长度、华丽措辞、危险升级或信息数量当成质量。

# 四项评分：各 0–4 分

- `scene_construction`（自主构建场景）：为未规定的现场创造有作用的行为、反应或情境，而非复述输入和结果。
- `causal_interaction`（因果互动）：行动引起具体回应，回应继续影响现场；人物有自己的目的与应对。
- `scene_development`（正文展开）：关键交锋通过动作、对白、反应实际发生，而非一句概述或重复描写。
- `playability`（可继续游玩）：正文结束时形成具体可利用、可回应的局面，而非抽象压力或外加选项。

统一分档：0 缺失或损害体验；1 只有表面表现，主要是结果说明；2 基本成立，但展开受限或机械；3 充分成立，具体连贯，支撑场景；4 表现突出，多个细节相互作用，形成自然且有分量的场景发展。

每项填写整数 `score`、从该篇正文精确复制的 `evidence` 和具体 `reason`。问自己：删掉新增内容，人物互动、因果过程或玩家可回应的局面是否受损？只增加颜色、声响、形容词不够；安静交谈也能得高分。不要要求每篇新增危机、秘密和重大转折。

# 违规单列

类别：`outcome` 行动结果反转、削弱、推迟或以收益补偿失败；`continuity` 违背明确历史、设定、资源与现场状态；`player_agency` 替玩家作出未经授权的实质行动或决定；`disclosure` 越权披露秘密或确立高影响身份、关系、世界事实；`internal_logic` 明确的内部因果、空间或数量矛盾。

每项包含正文精确引文 `evidence`、具体权威依据或权限边界 `authority`、为何冲突的 `reason` 和严重度 `severity`：

- `local`：修一个细节即可，场景主体仍成立。
- `major`：破坏结果、玩家主导权、秘密边界或关键连续性，需要重构场景。

没有违规填空数组。“输入没提到”“没有检索证据”不是违规理由。允许兼容的新事实；NPC 说过某事不等于旁白证明此事真实。判断依据不足时，不制造违规。

违规不覆盖质量分。分别评价写得怎样和是否越界，可以出现质量高但违规多的结果。

# 成对偏好

完成两篇独立评分后，`preference` 选 `left`、`right` 或 `tie`，`reason` 用两篇具体互动解释差异；重大违规是否影响采用价值也在此说明。不要因一篇更长或危险更大而自动偏好它。

输入中的人物动机和隐藏信息供核查认知与权限使用，不要求正文把这些信息全部揭露。


# 人工试读校准要点

- 具体人物、地点及其关系可以形成自然的调查入口和世界扩展空间。
- 态度变化需要行动、问答或现场事件推动，单方面连续表现情绪不能代替因果互动。
- 核对对白之间的逻辑承接，以及正文实际达成的结果；结果锚点写成功不等于正文已经演出成功。
- 人物性格可有多种合理演绎；精明、收钱办事和说话留半句可以同时成立。
- 正文长度与质量分别观察，新增感官和情绪描写不自动提高场景构建分。
